👑 TUGAS LEADER — Membuat Endpoint Register & Login

Branch: fitur/api-auth

Deskripsi

Tugas kamu minggu ini bikin dua endpoint sekaligus. Yang pertama Register, yaitu API buat nerima pendaftaran akun baru (nama, email, password, role). Password yang masuk harus diacak dulu pakai bcrypt biar aman, baru disimpen ke database. Yang kedua Login, yaitu API buat ngecek email dan password. Kalau cocok, sistem kasih JWT Token (semacam kartu identitas digital) yang nanti dipake user buat akses fitur-fitur lain.

Langkah-Langkah

Persiapan Awal

  1. Clone repo kalau belum:
    2. git clone https://github.com/BagasD-Tara/Web-Ruang-Dosen.git
cd Web-Ruang-Dosen
  2. Jalankan npm install di root folder.
  3. Masuk ke folder apps/api/, buat file .env dan isi sesuai panduan setup.
  4. Masih di folder apps/api/, jalankan:
    5. npx prisma generate
npx prisma migrate dev
  5. Balik ke root folder, tarik perubahan terbaru lalu bikin branch:
    6. git checkout develop
git pull origin develop
git checkout -b fitur/api-auth

Mulai Coding

  1. Install library tambahan di folder apps/api/: bcrypt, @types/bcrypt, @nestjs/jwt, @nestjs/passport, passport, passport-jwt, @types/passport-jwt.
  2. Buka folder apps/api/src/auth/. Dua file yang kamu kerjain:
    • auth.service.ts → tempat nulis logika
    • auth.controller.ts → tempat bikin endpoint
  3. Buka auth.service.ts. Di file ini:
    • Import PrismaService dan JwtService, masukin ke constructor.
    • Bikin fungsi register (nerima name, email, password, role). Cek email duplikat, hash password pakai bcrypt, simpen ke DB pakai prisma.user.create, return data user tanpa password.
    • Bikin fungsi login (nerima email, password). Cari user berdasarkan email, cocokkan password pakai bcrypt.compare, kalau cocok bikin token pakai jwtService.sign, return access_token.
  4. Buka auth.module.ts. Daftarkan JwtModule dengan secret dari JWT_SECRET dan expiresIn 24h.
  5. Buka auth.controller.ts. Bikin dua route: @Post('register') dan @Post('login').

Kalau Bingung

Buka file apps/api/prisma/schema.prisma, cari bagian model User buat liat field-field-nya.

Selesai? Push ke GitHub

git add .
git commit -m "feat: tambah endpoint register dan login"
git push origin fitur/api-auth

Buka GitHub → buat Pull Request ke branch develop (bukan main).

👤 TUGAS TIO — Membuat Endpoint Kuis Baru

Branch: fitur/api-quiz

Deskripsi

Kuis itu ujian singkat yang Dosen buat buat ngetes Mahasiswa. Di aplikasi kita, kuis ini ada sistem poin XP-nya (kayak di game). Jadi kalau Mahasiswa lulus, dia dapet poin. Tugas kamu minggu ini itu bikin API-nya supaya Dosen bisa bikin kuis baru. Data yang disimpen itu judul kuisnya, kuis ini buat matkul apa, berapa poin XP-nya, dan berapa nilai minimum buat lulus.

Langkah-Langkah

Persiapan Awal

  1. Clone repo kalau belum:
    2. git clone https://github.com/BagasD-Tara/Web-Ruang-Dosen.git
cd Web-Ruang-Dosen
  2. Jalankan npm install di root folder.
  3. Masuk ke folder apps/api/, buat file .env dan isi sesuai panduan setup.
  4. Masih di folder apps/api/, jalankan:
    5. npx prisma generate
npx prisma migrate dev
  5. Balik ke root folder, tarik perubahan terbaru lalu bikin branch:
    6. git checkout develop
git pull origin develop
git checkout -b fitur/api-quiz

Mulai Coding

  1. Buka folder apps/api/src/quiz/. Dua file yang kamu kerjain:
    • quiz.service.ts → tempat nulis logika
    • quiz.controller.ts → tempat bikin endpoint
  2. Buka quiz.service.ts. Di file ini:
    • Import PrismaService, masukin ke constructor.
    • Bikin fungsi create yang nerima 4 data: title, courseId, xpReward, minScore.
    • Cek dulu courseId-nya ada gak di DB pakai this.prisma.course.findUnique. Kalau gak ada, kasih error.
    • Kalau ada, simpen pakai this.prisma.quiz.create. Return hasilnya.
  3. Buka quiz.controller.ts. Masukin QuizService ke constructor. Bikin route @Post() yang nerima @Body(), panggil fungsi create.

Kalau Bingung

Buka apps/api/prisma/schema.prisma, cari model Quiz. Atau liat folder src/auth/ buat contoh pattern.
